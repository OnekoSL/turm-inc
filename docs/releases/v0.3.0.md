# Turm INC v0.3.0

Das erste öffentliche, spielbare Windows-Release von Turm INC. Ein Fantasy-Incremental, in dem du ein instabiles Turmnetzwerk leitest und mit dem Obsidianbund um Magieaufträge konkurrierst.

## Download und Start

1. **Turm-INC-0.3.0-win32-x64.zip** unter „Assets“ herunterladen (Windows x64, ca. 165 MiB).
2. Das ZIP vollständig entpacken.
3. Im entpackten Ordner **Turm INC/Turm INC.exe** starten.

Keine Installation von Node.js, kein Entwicklungsserver und keine Internetverbindung zum Spielen erforderlich. Die automatisch von GitHub angebotenen „Source code“-Archive enthalten den Quellcode; zum Spielen das Windows-ZIP verwenden.

## Enthalten

- Neun Türme in sechs Elementen mit lokalen Produktions-, Raum- und Betriebsboni.
- Einzelsteuerung und gemeinsame Betriebsbefehle je Element.
- Wohnräume, Küchen, Bibliotheken, Resonanzräume und Lager; Minions, Nahrung, Wissen und Harmoniekristalle.
- Fünf dauerhafte Forschungen und automatisch versorgte Kristallstabilisierung.
- Gemeinsame Magieaufträge gegen den Obsidianbund mit vier sichtbaren Konkurrenzstufen.
- Deutsche und englische Oberfläche, lokale Spielstände und Übernahme älterer Spielstände.
- Vollständige Pause bei Fokusverlust, Minimieren und manueller Pause. Keine Offline-Erträge.

Die sechs zusätzlichen Türme werden nach Abschluss der Einführung freigegeben. Die Sprache lässt sich im Spiel und im Pausenfenster wechseln.

## Prüfung und Prototypstatus

83 automatisierte Tests und acht Desktop-Szenarien bestanden, einschließlich Offline-Start, Speicherung, Migration und beider Sprachen. Drei simulierte Durchläufe erreichen alle neun Türme ohne geschenkte Ressourcen nach 34–35 aktiven Minuten. Balance und Spielgefühl benötigen weiterhin menschliche Spieltests; besonders Wartezeiten und die Häufigkeit der Betriebswechsel.

## English

The first public playable Windows release of Turm INC: manage nine unstable magical towers across six elements, assign minions to rooms, research permanent improvements, and compete for magic contracts.

Download **Turm-INC-0.3.0-win32-x64.zip**, extract the entire archive, then run **Turm INC/Turm INC.exe**. No Node.js installation, development server or internet connection is needed to play. Select English in the game or pause menu. Progress is saved locally; older saves are migrated automatically. Losing focus or minimizing pauses the entire world, with no offline production.

This is a playable prototype. Automated checks pass, but balance and pacing still need human playtesting. **Image owner: Nevico.**
